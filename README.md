# Novel Translator

Aplikasi web untuk menerjemahkan teks novel dengan hasil yang menyerupai terjemahan manusia (HTL).

## Struktur Proyek
- `index.html`: Antarmuka pengguna
- `style.css`: Styling untuk antarmuka
- `script.js`: Logika penerjemahan
- `assets/`: Folder untuk menyimpan aset

## Cara Menggunakan
1. Masukkan teks novel yang ingin diterjemahkan di textarea.
2. Klik tombol "Terjemahkan".
3. Hasil terjemahan akan ditampilkan di bawah.

## Kunci API
Ganti `YOUR_API_KEY_HERE` dan `YOUR_OPENAI_API_KEY` dengan kunci API yang valid untuk menggunakan fitur penerjemahan.
